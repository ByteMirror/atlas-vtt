# Display Image on Player View Feature

This feature allows the Dungeon Master to quickly show images to players on the player view window.

## How to Use

### Method 1: Command Palette
1. Open the Player Window first (use command "Atlas: Open Player Window (Popout)")
2. Open an image file in Obsidian
3. Open command palette (Cmd/Ctrl + P)
4. Search for "Display Image on Player View"
5. Press Enter

### Method 2: Ribbon Icon
1. Open the Player Window first
2. Open an image file in Obsidian
3. Click the monitor icon in the left sidebar ribbon
4. The image will appear on the player view

### Method 3: File Explorer Context Menu
1. Open the Player Window first
2. Right-click on an image file in the file explorer
3. Select "Display on Player View" from the context menu

## Image Controls

Once displayed on the player view:
- **Zoom**: Scroll with mouse wheel (scale range: 0.1x to 5x)
- **Pan**: Click and drag to move the image
- **Reset**: Double-click to reset zoom and position
- **Close**: Click the X button or press ESC

## Supported Image Formats
- PNG
- JPG/JPEG
- GIF
- BMP
- SVG
- WebP

## Notes
- The image appears centered on a dark semi-transparent background
- The display is borderless for a clean presentation
- Multiple images can be displayed sequentially (previous image is replaced)
